# Visual Identity Canon

本文档是 ImageGen、CG 接入和审稿的硬约束。角色外观以现有立绘为准，不能因为 CG 场景、服装或构图变化而漂移。

## 林澈

必须保持：

- 黑色及肩短发 / bob，发尾微内扣，不是长发。
- 蓝灰色眼睛，不得改成棕、红、紫或高饱和蓝。
- 右侧金色星星发卡是强识别点，校服与关键 CG 优先保留。
- 深蓝校服外套、白色滚边、白衬衫、深蓝蝴蝶结、深蓝百褶裙。
- 气质克制、认真、安静，情绪靠眼神、手势和肩膀紧绷表现。
- 常用道具是黑笔、深色天文笔记本、星图或透明文件袋。

禁止：

- 长发、披肩长直发、双马尾、卷发、浅发色。
- 换眼睛颜色或画成另一套脸型。
- 偶像化摆拍、过度亲密姿势、夸张哭脸、成人化装扮。
- 没有剧情理由时移除发卡。

## CG 接入审查

接入任何含林澈的 CG 前，必须先做人工目检：

1. 发型是否仍是及肩短发 / bob。
2. 眼睛是否仍是蓝灰色。
3. 校服 CG 是否有右侧金色星星发卡。
4. 脸型和气质是否像 `assets/char/lin-neutral.png`。
5. 如果任一项不通过，该 CG 只能留作废稿，不能放进 `assets/cg` 或 `script.js`。
