# 《星图未定》剧本写作方案与样张

本文档用于后续扩写 `script.js` 的 `STORY.chapters[].sections[].lines[]`。所有情感推进保持单女主林澈线：周行与林澈是唯一恋爱主轴；夏南星负责节奏、组织和轻喜剧；顾望舒负责竞赛压力与成熟镜像，不写恋爱暧昧。

## 写作总原则

- 叙事视角以周行为主，旁白写他的观察、误判和自我修正。玩家代入点不是“他天然优秀”，而是“他能不能诚实面对自己不够好、怕落后、想靠近林澈却不敢拖累她”。
- 天文术语只在人物行动中出现，避免说明书式科普。术语承担情绪隐喻：赤经差是第一次错位，雨线是误差和焦虑，春季大曲线是并肩方向。
- 选项不做简单善恶，而是区分玩家选择的关系策略：坦白或回避、拆解问题或用目标压住情绪、同步未来或提前替对方决定。
- 林澈的吸引力来自“准确、克制、认真到有点笨拙”。她不是万能冷面学霸，她会因为不确定条件焦虑，也会在别人真正听懂她时露出很轻的放松。
- 早期甜度尽量藏在学习合作里：她帮他纠错，他帮她把复杂问题讲成模板；她指出他的最后一步没错，他看见她其实也怕失控。

## 台词质量基准

当前扩写优先解决“台词过短、不像人说话、每句都想当金句”的问题。后续写入 `script.js` 时，先保证场景可信，再追求漂亮句子。

### 明确禁止

- 禁止概念化短句堆叠：不要连续写“误差会累积”“人也会”“星图是路本身”这类抽象句。它们可以偶尔出现在章末或情绪顶点，但一个 section 最多 1 句。
- 禁止口号式台词：角色不要直接说主题，例如“我们要选择同一片天空”“错误不是判决”。主题应通过动作、选择和后续反应体现。
- 禁止过度机智吐槽：周行可以自嘲，但不能每次接话都像段子。夏南星可以调节气氛，但不能把训练、招新、冲突都说成脱口秀。
- 禁止每句都短促有力：正常高中生对话会有迟疑、重复、补充、没说完的话，也会说“不是，我的意思是”“等一下”“你先别翻页”。
- 禁止用设定说明代替交流：不要让人物为了告诉玩家而说“我是高二一班，目标 CNAO 决赛”。信息要从报名表、社团通知、老师催促、题目讨论里自然漏出。
- 禁止角色过早互相命名式理解：第一章不要让周行马上看穿林澈的“脆弱”和“追梦本质”。他只能先观察到她认真、说话直接、好像真的懂题。

### 更自然的写法标准

- 高中生口吻：句子允许不完整，允许临时改口。周行的玩笑要像缓解尴尬，不像准备好的妙语；林澈的准确要像做题习惯，不像哲学判断。
- 行动描写：每 3-5 句台词之间插入具体动作或环境反馈，例如翻草稿纸、遮住答案、看报名截止日期、椅子腿刮地、窗外广播响起。
- 心理活动：周行旁白要写“当下误会”和“事后修正”的过程。不要直接判定林澈是什么样的人，而是写他先觉得丢脸、再发现她没有嘲笑。
- 停顿和话题转移：尴尬时不要立刻抛金句。可以让人物看题、喝水、收拾书、被上课铃或夏南星打断，再把话题转到集训、报名、训练安排。
- 信息密度：一屏最好只承担一个新信息。CNAO、初赛、社团集训、决赛目标、训练时间不要挤在同一段台词里；先出现报名表，再出现社团，再出现目标。
- 台词长度：单句台词以 18-45 个汉字为主，关键解释可到 60-80 字；连续短句不得超过 3 句。旁白可稍长，但要有具体物件和动作。
- 选项前铺垫：选项出现前必须让玩家知道周行为什么犹豫。不要在没有心理压力的情况下直接给“接受/玩笑”。
- 每个 section 目标长度：正式写入游戏时，普通 section 建议 45-80 条 `lines`；章节开场和情绪爆点可到 80-120 条；仅做骨架时才允许 5-10 条。每个 section 至少包含 1 个生活化场景动作、1 个人物小误会或小退让、1 个推进主线的信息点。
- 样张长度：样张不必完整覆盖 section，但应展示完整的起承转合。第 1 章样张建议 25-45 条 `lines`，避免只给几句概念预告。

## 人物声音表

### 周行

| 维度 | 写法 |
| --- | --- |
| 语气 | 第一人称旁白偏敏感、自嘲、带一点少年式嘴硬；台词比内心轻，遇到压力会先找普通话题垫一下。 |
| 口头习惯 | 偶尔把压力类比成题目，但频率要低；更多时候会说“等一下”“我不是这个意思”“这题我刚卡住”。 |
| 回避方式 | 用玩笑、效率、替对方考虑来绕开真实恐惧；常把“我怕追不上”说成“先过初赛再说”。 |
| 情绪爆发方式 | 不会大吼，更多是语速变快、抢结论、跳步骤；爆发句短而硬，例如“我没时间把每一步都写成论文。” |
| 轻松桥段 | 让他承担少量吐槽和接梗，但不能油滑。笑点来自尴尬里的普通反应，随后要回到行动。 |

写作注意：周行的成长线是从“怕显得不够格”到“愿意承认我现在不够，但我会把问题拆开”。他的动人之处在于越来越少用玩笑保护自己。

### 林澈

| 维度 | 写法 |
| --- | --- |
| 语气 | 句子干净、判断明确，少用夸张词；情绪越强，越倾向于把话说得更准确。 |
| 口头习惯 | 会先纠正条件和定义，例如“准确说”“这个条件不能省”“近似要放到最后”。 |
| 回避方式 | 把感受改写成计划、表格、推导和复盘；不说“我害怕”，而说“如果条件不完整，结论不可靠”。 |
| 情绪爆发方式 | 先沉默，再执着于一个细节；真正爆发时不是哭喊，而是把自我否定说得极其冷静，例如“我只是刚好擅长把错误藏到最后一步。” |
| 轻松桥段 | 轻微认真过头，接周行的玩笑时会把玩笑当成可修正命题；偶尔露出很淡的笑，杀伤力比甜言蜜语强。 |

写作注意：林澈不是“需要被拯救”的女主。周行能给她的不是答案，而是允许她把问题拆小、允许她不完美仍然继续喜欢天文。

### 夏南星

| 维度 | 写法 |
| --- | --- |
| 语气 | 明快、锋利、带社长式控场感；能把沉重训练说成可执行任务。 |
| 口头习惯 | 喜欢给状态下诊断和标签，例如“坐标系恐惧症”“清醒，加一分”“粗心不是物理量”。 |
| 回避方式 | 她很少回避情绪，而是把情绪转成安排；当她不想煽情，会用玩笑把人推回正轨。 |
| 情绪爆发方式 | 不是失控，而是突然收掉笑意，给出清楚边界：“集训不是让你们互相证明谁更能硬撑。” |
| 轻松桥段 | 负责打断暧昧、宣布训练、吐槽两人过度认真；每场最多一两个玩笑，其余时间要像真的社长在处理人和事。 |

写作注意：夏南星是导师型配角。她看得出周行和林澈的关系变化，但不要让她直接撮合到破坏细腻感。

### 顾望舒

| 维度 | 写法 |
| --- | --- |
| 语气 | 平稳、客观、有边界；很少安慰，常直接指出问题的结构。 |
| 口头习惯 | 用“第一、第二、第三”拆分问题；强调稳定性、前提、近似条件和真实损失。 |
| 回避方式 | 不谈自己的遗憾时，会把话题转回方法；她不卖惨，偶尔用一句很轻的事实暴露经历。 |
| 情绪爆发方式 | 几乎不爆发。她的压迫感来自不留情面的准确，例如“真正丢分的通常不是公式，是你们以为题目默认了什么。” |
| 轻松桥段 | 轻微冷幽默，像认真给周行的玩笑做误差分析。不能写成傲娇或恋爱竞争者。 |

写作注意：顾望舒是“更成熟的竞赛者”，她让林澈看见另一种优秀：可以承认错误、可以输过一次、也可以继续稳定地前进。

## 章节爆点与扩写方向

### Chapter 1：春分前的星图

- 爆点 1：林澈第一次纠错。场景要抓住“冒犯感”和“被认真看见”的双重感觉。周行不应立刻欣赏她，而是先不服，再被她的准确吸引。
- 爆点 2：楼顶春季大曲线。林澈说“你看见了”，章末再补“最后一步没错”。这是第一章最适合做玩家截图和回味的情绪点。
- 可扩写钩子：训练表里林澈承认天体力学不稳。要让玩家意识到她不是高不可攀，而是会把脆弱藏进一句“这一块我需要重做”。

### Chapter 2：雨线和误差

- 爆点 1：顾望舒红笔指出标准答案不严谨。她的出现要让玩家感到外部强者压迫，但不能抢林澈位置。重点是林澈没有退开，而是把草稿纸推到中央。
- 爆点 2：第一次争执。周行“人也会”与林澈“误差会累积”形成情绪对撞，是第二章最强场景。
- 可扩写钩子：雨停前的约定。把和解落在行动上：一个人焦虑时，另一个人负责把问题拆小。不要写成抽象承诺，写成他们交换笔记和模板。

## 后续落地建议

- `trust` 增长要绑定“坦白脆弱”和“理解对方压力来源”，不要只绑定温柔台词。
- `discipline` 增长要绑定具体执行方案：错题分类、条件清单、限时策略、训练表复盘。
- `future_sync` 在前两章暂不急着出现，最多埋伏“决赛之后怎么办”的轻微问题；第五章以后再成为主轴。
- 插入分支建议保持 2-4 句，不改变大事件，只改变关系温度和玩家对周行的代入感。
- 林澈线的糖点优先写“确认、并肩、把对方的方法带进自己的解题方式”，少写外露撒娇或吃醋。
